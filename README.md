# 🏠 Home Services Auth UI (React + Tailwind CSS)

A fully responsive authentication UI built using **React**, **Vite**, and **Tailwind CSS v4**, featuring clean design for login, signup, and forgot password flows. The app includes modular routing, Google Fonts, and dynamic navigation handling.

---

## 🔧 Tech Stack

- ⚛️ **React 19**
- ⚡ **Vite**
- 🎨 **Tailwind CSS v4**
- 🔁 **React Router DOM v6**
- 🎯 **React Icons**
- 🧼 **Prettier** with Tailwind plugin
- 🔤 **Google Fonts:** Work Sans & Montserrat

---

## 📁 Folder Structure

src/
├── assets/ # Logo and static images
├── components/ # Reusable components (e.g., Header)
├── pages/ # Login, Signup, ForgetPassword
├── routes/ # AppRoutes.jsx (central routing)
├── App.jsx # App wrapper with BrowserRouter
├── index.css # Tailwind & font imports
└── main.jsx # React root entry point

---

## 📌 Features

- ✅ Responsive login and signup forms
- ✅ Forgot password page
- ✅ Modular routing (`src/routes/AppRoutes.jsx`)
- ✅ Header with dynamic hiding on `/forget-password`
- ✅ Custom Google Fonts (Work Sans & Montserrat)
- ✅ React Icons support
- ✅ Active link highlighting
- ✅ Font styling without `tailwind.config.js`
